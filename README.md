# Assignment 2 – Computational Gastronomy
Data: recipe_id_ingredient_name.csv (9,999 recipes, 13,226 unique ingredient names after cleaning/dedup).
Run: python3 Q1.py; python3 Q2.py; python3 Q3.py  (outputs go to outputs/)

- Q1.py: Apriori (size 1-3). Q1a_* complete lists (size 2/3 listed for itemsets in >=2 recipes; size 1 complete), Q1b_* top 20, Q1c_definitions.txt + example rules.
- Q2.py: Q2a (replica, 10 sets) and Q2b (inverse transform, 10x recipes) size distributions.
- Q3.py: Q3a size distribution, Q3b frequency-rank (10 random cuisines, size + frequency controlled).
